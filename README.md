# Календари матчей

`calendars/<клуб>.ics`: все матчи клуба во всех турнирах сезона (лига, кубок, суперкубок, товарищеские) по календарю sports.ru. Для клубов ФНЛ матчи лиги берутся из API fnl.pro: там есть окна дат для неназначенных туров, трансляции, билеты, судья и стадион. Если ФНЛ недоступна, лига на этот прогон берётся с sports.ru. GitHub Actions пересобирает их каждые 3 часа и коммитит, только если что-то изменилось. Если sports.ru поменяет вёрстку и парсер сломается, прогон упадёт (придёт письмо от GitHub), а старый файл останется на месте.

- точные дата и время → событие на 2 часа (время МСК, айфон покажет в своём поясе);
- время не назначено → событие на весь день с ⏳;
- дня ещё нет (ФНЛ) → событие с ⏳ на всё окно тура «с … по …», время в календаре не занимает; у sports.ru окна нет, там день ориентировочный (первый день тура);
- сыгранные матчи → в названии счёт.

У каждого события постоянный ID (id матча ФНЛ или сезон+турнир+соперник+поле для sports.ru), поэтому при переносе событие переезжает, а не дублируется.

## Клубы

Список — словарь `CLUBS` в `generate.py`. Ключ — слаг клуба из URL `sports.ru/football/club/<слаг>/`; для клуба ФНЛ добавь блок `fnl` (лига, слаг на fnl.pro, слаг турнира на sports.ru, который он заменяет).

## Подписка на айфоне

Настройки → Приложения → Календарь → Учётные записи → Добавить → Другое → «Подписной календарь», URL:

```
https://raw.githubusercontent.com/<user>/<repo>/main/calendars/ural.ics
https://raw.githubusercontent.com/<user>/<repo>/main/calendars/zenit.ics
```

Каждый клуб — отдельный календарь, со своим цветом, и его можно отключить отдельно.

## Локально

```bash
python3 generate.py calendars
```
